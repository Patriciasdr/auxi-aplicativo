Objetivo do desafio

Avaliar organização de código, raciocínio de fluxo e cuidado com a experiência do usuário.

O cenário simulado: clientes cadastrados em sistemas diferentes precisam de um login unificado. Para quem usa o app isso deve ser invisível — só o CPF é informado, e o sistema decide o caminho.

Situação 1

Acesso direto

CPF encontrado na base → avança para a tela de senha e libera o login.

Situação 2

Bloqueio de cadastro

CPF não encontrado → modal empático orienta a procurar o gerente, sem permitir login. O bloqueio acontece antes de pedir senha.

O que foi pedido × o que foi entregue

O desafio pedia uma tela. Entreguei um aplicativo.

Os dois fluxos obrigatórios foram implementados exatamente como especificado — com dados de teste fiéis ao enunciado. A partir daí, o projeto virou o app real da Auxiliadora Digital, com backend próprio.

Escopo original

Tela de identificação por CPF

Máscara, validação, botão Continuar, saudação com nome, senha simulada e modal de bloqueio — dados fixos no código.

Entregue

App completo com Supabase

Autenticação real (Auth + RPC), sessão persistida com SecureStore, e 10 módulos funcionais além do login: boletos, dashboard, circulares, agenda, reservas, mudanças, reparos, fale com a diretoria e notificações em tempo real.

  • Máscara e validação de CPF (000.000.000-00), com estado de carregamento
  • Fluxo de acesso direto e fluxo de bloqueio, exatamente como o termo pede
  • Regra de identificação migrada do código para uma RPC no Supabase — camada de serviço real, não mockada
  • Controle de acesso por perfil (síndico, gestor, morador, proprietário, zelador, administradora…)
  • TypeScript, componentização e 6 suítes com 34 testes automatizados
  • README e documentação funcional detalhada de todas as regras de negócio

    Arquitetura e stack

    Cliente React Native, com Supabase como backend.

    Autenticação via Supabase Auth + RPC de identificação por CPF; sessão persistida com SecureStore/AsyncStorage; regras de negócio (aprovação de reservas, regras de mudança, cobrança) configuráveis por condomínio direto no banco.

    Expo SDK 57 React Native 0.86 React 19.2 TypeScript 6 React Navigation 7 Supabase Auth · RLS · RPC · Realtime Jest + Testing Library
